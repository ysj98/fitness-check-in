# 运动打卡小程序

微信小程序运动打卡应用，包含微信小程序前端、Node.js 后端 API、MySQL 数据库和 PM2 部署配置。前端仅面向微信小程序，不包含 H5、App 或其他小程序平台代码。

## 项目功能

### 打卡

- 微信登录
- 一键打卡
- 每日多次打卡
- 今日打卡次数
- 今日打卡记录
- 最近打卡记录
- 今日记录删除
- 打卡成功动态效果

### 日历

- 月度打卡日历
- 上月、下月切换
- 每日打卡次数展示
- 有打卡日期状态标记

### 连续打卡

- 连续打卡天数展示
- 按自然日统计
- 每天至少一次打卡计入连续天数

### 体重、身高与 BMI

- 体重记录与历史补录
- 公斤、斤显示切换
- 身高和目标体重维护
- BMI 自动计算与中国成人标准分级
- 7 天、30 天、90 天体重和 BMI 趋势
- 同日多次记录与每日趋势聚合
- 历史记录编辑、删除和分页查看

### 我的

- 微信头像选择
- 头像上传保存
- 微信昵称填写
- 昵称保存
- 性别维护
- 生日维护
- 身高维护
- 每日打卡目标维护
- 个人资料查看

### 后端

- 微信小程序登录换码
- JWT 登录鉴权
- 用户资料查询
- 用户资料更新
- 头像文件上传
- 头像静态访问
- 今日打卡统计
- 月度打卡统计
- 连续打卡统计
- 最近打卡记录查询
- 打卡记录创建
- 打卡记录删除
- 体重记录创建、查询、编辑和删除
- 体重趋势与 BMI 统计
- 身高、目标体重和显示单位维护

## 页面

### 打卡页

打卡页展示今日状态、连续天数、打卡按钮、今日记录、最近记录和月度日历。

### 我的页

我的页展示并维护头像、昵称、性别、生日、身高和每日打卡目标。

### 体重页

体重页展示当前体重、目标距离、BMI、趋势图和历史记录，并提供记录与设置入口。

## 技术栈

- 前端：uni-app、Vue 3、TypeScript、UnoCSS
- 后端：Node.js、Fastify、Prisma、MySQL
- 部署：PM2、Nginx、Certbot
