# 运动打卡小程序

微信小程序运动打卡应用，包含微信小程序前端、Node.js 后端 API、MySQL 数据库和 PM2 部署配置。前端仅面向微信小程序，不包含 H5、App 或其他小程序平台代码。

## 项目功能

### 打卡

- 微信登录
- 点击打卡后选择运动类型和运动时长
- 运动类型支持散步、跑步、健身、骑行、游泳、瑜伽和其他
- 运动时长支持 15、30、45、60、90 分钟快捷选择和 1-300 分钟自定义输入
- 自动记住用户上次选择的运动类型和时长，作为下次打卡默认值
- 每日多次打卡
- 今日打卡次数
- 今日累计运动分钟数
- 今日打卡记录展示运动类型和运动时长
- 最近 7 天按自然日展示运动次数、累计分钟数和未打卡状态
- 今日记录删除
- 打卡成功动态效果
- 补签过去 30 天内未打卡日期，每个自然月最多 3 次

### 日历

- 月度打卡日历
- 上月、下月切换
- 每日打卡次数展示
- 有打卡日期状态标记
- 月度热力展示补签日期橙色角标
- 月度日历点击过去未打卡日期可发起补签
- 月度日历展示本月补签次数

### 连续打卡

- 连续打卡天数展示
- 按自然日统计
- 每天至少一次打卡计入连续天数
- 补签成功后计入打卡天数并重新计算连续打卡

### 体重、身高与 BMI

- 体重记录与历史补录
- 公斤、斤显示切换
- 身高和目标体重维护
- BMI 自动计算与中国成人标准分级
- 7 天、30 天、90 天体重和 BMI 趋势
- 同日多次记录与每日趋势聚合
- 历史记录编辑、删除和分页查看

### 我的

- 微信头像选择
- 头像上传保存
- 微信昵称填写
- 昵称保存
- 性别维护
- 生日维护
- 身高维护
- 每日打卡目标维护
- 个人资料查看
- 我的成就按“成就系列 + 当前冲刺阶段”展示
- 成就详情弹层展示系列内全部阶段
- 成就总进度按已完成阶段数 / 全部阶段数计算
- 成就系列包含累计打卡、连续打卡、体重记录和个人资料

### 后端

- 微信小程序登录换码
- JWT 登录鉴权
- 用户资料查询
- 用户资料更新
- 头像文件上传
- 头像静态访问
- 今日打卡统计
- 月度打卡统计
- 月度补签统计
- 连续打卡统计
- 最近打卡记录查询
- 打卡记录创建，保存运动类型和运动时长
- 补签打卡创建
- 打卡记录删除
- 阶段式成就进度查询
- 体重记录创建、查询、编辑和删除
- 体重趋势与 BMI 统计
- 身高、目标体重和显示单位维护

## 页面

### 打卡页

打卡页展示今日状态、今日累计运动分钟数、连续天数、打卡按钮、今日记录、最近 7 天和月度日历。点击“立即打卡”会打开打卡弹窗，用户选择运动类型和运动时长后确认提交；最近 7 天默认展示最近 3 天，可展开查看完整 7 天，并在可补签的未打卡日期提供补签入口。

### 我的页

我的页展示并维护头像、昵称、性别、生日、身高和每日打卡目标，并展示阶段式成就进度。

### 体重页

体重页展示当前体重、目标距离、BMI、趋势图和历史记录，并提供记录与设置入口。

## 技术栈

- 前端：uni-app、Vue 3、TypeScript、UnoCSS
- 后端：Node.js、Fastify、Prisma、MySQL
- 部署：PM2、Nginx、Certbot
