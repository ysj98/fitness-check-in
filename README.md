# 运动打卡小程序

微信小程序运动打卡应用，包含小程序前端、后端 API、MySQL 数据库和 Docker 部署配置。

## 项目功能

### 打卡

- 微信登录
- 一键打卡
- 每日多次打卡
- 今日打卡次数
- 今日打卡记录
- 最近打卡记录
- 今日记录删除
- 打卡成功动态效果

### 日历

- 月度打卡日历
- 上月、下月切换
- 每日打卡次数展示
- 有打卡日期状态标记

### 连续打卡

- 连续打卡天数展示
- 按自然日统计
- 每天至少一次打卡计入连续天数

### 我的

- 微信头像选择
- 头像上传保存
- 微信昵称填写
- 昵称保存
- 性别维护
- 生日维护
- 个人资料查看

### 后端

- 微信小程序登录换码
- JWT 登录鉴权
- 用户资料查询
- 用户资料更新
- 头像文件上传
- 头像静态访问
- 今日打卡统计
- 月度打卡统计
- 连续打卡统计
- 最近打卡记录查询
- 打卡记录创建
- 打卡记录删除

## 页面

### 打卡页

打卡页展示今日状态、连续天数、打卡按钮、今日记录、最近记录和月度日历。

### 我的页

我的页展示并维护头像、昵称、性别和生日。

## 技术栈

- 前端：uni-app、Vue 3、TypeScript、UnoCSS
- 后端：Node.js、Fastify、Prisma、MySQL
- 部署：Docker Compose、Nginx、Certbot
